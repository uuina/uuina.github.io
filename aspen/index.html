STEP BY STEP TUTORIAL

人工安装教程

按照以下六个步骤依次操作，避开常见卡顿与报错即可顺利完成。

步骤一

系统准备与环境要求

安装前必须确认系统满足以下三项基础要求，否则后续极易出现闪退或数据库故障：

  • 纯英文路径：当前电脑的 Windows 用户名和计算机名称必须全为英文字母，不能包含任何中文或空格。
  • 充足磁盘空间：请确保 D 盘拥有 30 GB 以上的可用剩余空间。
  • 开启 Windows 必备功能：进入系统控制面板，找到程序和功能下的启用或关闭 Windows 功能，勾选 .NET Framework 3.5 以及 Internet Information Services 相关选项，点击确定等待系统自动启用完成。
步骤二

安装前置依赖组件

解压下载好的压缩包，进入 01-组件 文件夹：

  • 找到 Microsoft SQL Express 2012 文件夹，运行安装程序 SQLEXPR_x64_ENU.exe，按照默认选项一路点击 Next 直到安装完毕。
  • 返回组件目录，找到 Access 数据库引擎安装包双击安装，为物性数据库提供支持。
步骤三

部署许可证服务与授权

老教程中通过管理工具逐条导入证书往往会导致界面未响应卡死半小时。这里推荐更简单快速的操作：

1. 安装服务：打开 02-破解\Sentinel RMS License Manager 8.5.1 文件夹，双击运行 Setup.exe 完成服务安装。

2. 放入授权文件：复制 02-破解 文件夹里的 lservrc 文件，直接粘贴到系统目录：
C:\Program Files (x86)\Common Files\SafeNet Sentinel\Sentinel RMS License Manager\WinNT

3. 重启服务：在电脑开始菜单搜索 服务 打开，找到 Sentinel RMS License Manager，鼠标右键点击并选择 重新启动。

4. 设置环境变量：打开电脑高级系统设置中的环境变量，在系统变量中点击新建，变量名填写 LSHOST，变量值填写你的当前计算机名称。

步骤四

安装 Aspen 主程序

打开 03-Aspen\aspenONE_V11_ENG 文件夹，鼠标右键点击 Setup.exe 选择以管理员身份运行。

  • 开始安装：点击界面上的 Install aspenONE products，勾选我同意许可协议，点击 Next。
  • 选择产品：勾选 Process Modeling Aspen HYSYS、Process Modeling Aspen Plus 以及 Aspen Exchanger Design & Rating。务必取消勾选 Server Products and Tools 和 Aspen Basic Engineering。
  • 修改安装路径：点击界面上方的 File Location 标签，把默认的 C 盘全部改成 D 盘路径。
  • 最关键步骤说明：进入许可证配置页面时，License server 和 License file 两个输入框必须保持完全空白，绝对不要点击 Add Server 添加计算机名，直接点击右下角 Next 跳过即可。
  • 设置密码：按提示输入密码例如 Aa123456。
  • 正式安装：点击 Install Now 开始安装，整个过程通常需要十五到二十分钟。
步骤五

安装中途报错处理

部分电脑在安装过程中可能会弹出一个提示找不到 vc_red.msi 临时路径的错误弹窗：

这是旧版运行库临时解压路径缺失导致的。解决非常简单：
找到 03-Aspen\aspenONE_V11_ENG\3rd Party Redistributables\Microsoft\VC80 目录下的 vcredist_x86.exe，将其解压后把里面的 vc_red.msi 复制到报错弹窗中指定的那个临时文件夹里，然后直接点击弹窗上的 OK 按钮即可顺利继续。
步骤六

完成安装与首次启动

向导提示安装完成后，点击 Finish 结束退出。

  • 首次从开始菜单启动 Aspen Plus 或 Aspen HYSYS 时，界面会弹出一个小窗口提示正在恢复物性数据库。
  • 这是正常的一次性初始化，通常需要一到三分钟时间。请耐心等待其自动配置完成后进入主界面，期间切勿强制结束进程。
