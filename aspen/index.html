极速人工安装指南

实测精炼重构版本，剔除冗余等待与重复点击，融入系统命令直达与底层避坑技巧。

新版精简实训指引 · 离线全量文档兜底说明

本指南为针对实际装机精炼重构的四阶段核心主线，大幅压缩了原本八十一步教程中的冗余点击。如果需要对照原始全量逐帧截图，在下载好的安装包解压目录中双击打开 Aspen Plus V11安装教程及注意事项.html 即可随时离线对照查阅。

第一阶段

环境准备与系统底层避坑

步骤 1

确认用户名与解压路径全英文

Windows 用户名必须为纯英文或数字组合，解压目录绝对不能放在带有中文名称的桌面上，否则后续数据库引擎与仿真核心必定崩溃报错。

单盘与多盘电脑指引：如果电脑只有单个 C 盘且可用空间大于三十吉字节，直接解压并安装在 C 盘即可，无需强行划分新分区；如果电脑有 D 盘等数据盘，建议解压并安装在 D 盘。
核心必看

新电脑与 Win11 固态硬盘扇区一键修复

高危故障预警：Windows 11 系统或近几年采用新式 NVMe 固态硬盘的轻薄本或游戏本，会向系统汇报大于 4KB 的物理扇区大小，导致后续安装 SQL Server 2012 时数据库引擎直接报红色叉号错误。

一秒解决办法：按键盘 Win + S 搜索 cmd，在右侧点击 以管理员身份运行，复制并运行下方整行命令，看到操作成功完成后 立即重启电脑： 
REG ADD "HKLM\SYSTEM\CurrentControlSet\Services\stornvme\Parameters\Device" /v "ForcedPhysicalSectorSizeInBytes" /t REG_MULTI_SZ /d "* 4095" /f
注意：执行该命令不会丢失任何数据，也不会伤及硬盘寿命，属于微软官方为老工业软件量身定制的标准兼容方案；重启电脑后底层存储驱动即可生效。
步骤 2

一键开启 Windows IIS Web 核心

Aspen 运行依赖系统的 IIS 基础组件。无需前往控制面板多层窗口翻找勾选，以管理员身份运行命令提示符，执行下方命令即可一秒静默启用： 
dism /online /enable-feature /featurename:IIS-WebServerRole /featurename:IIS-HostableWebCore /all /norestart
步骤 3

暂时关闭杀毒软件与防火墙

安装过程中需要向系统注册底层服务，请暂时退出各类第三方杀毒软件，并在安全中心中暂时关闭网络防火墙保护项。
第二阶段

安装前置运行库与 SQL 2012 数据库

步骤 4

安装 .NET Framework 运行库

打开解压后的 01-组件 文件夹：
1. 右键以管理员身份运行 framework 3.5 安装包，点击下载并安装此功能；若系统已内置则直接继续。
2. 右键以管理员身份运行 framework 4.7.1 安装包，提示已安装此更新直接关闭，未安装则按提示完成。
步骤 5

安装 SQL Server 2012 数据库

进入 sql2012 文件夹，右键 setup.exe 选择以管理员身份运行：
1. 点击第一个 全新 SQL Server 独立安装 选项。
2. 勾选同意许可条款，功能选择保持默认。
3. 实例配置保持选择 默认实例，后续的服务账户与身份验证直接保持默认点击 Next。
4. 耐心等待安装进度走完，直到全部显示绿色对勾，点击 Close 关闭向导。

若此处提示 Database Engine Services 出现红色叉号 Failed，说明电脑为新固态硬盘，请对照第一阶段运行扇区修复命令并重启后再装。
第三阶段

部署许可证服务与极速授权激活

步骤 6

安装 Sentinel RMS 许可证管理器

进入 02-许可证\Sentinel RMS License Manager 8.5.1 目录，右键 Setup.exe 选择以管理员身份运行。勾选接受协议，安装类型务必勾选 Complete 完整安装，一路点击 Next 直到安装完成并点击 Finish。
步骤 7

一键配置 LSHOST 环境变量

原本需要手动在控制面板中经过七个窗口反复查找电脑名称并新建系统变量。现在只需以管理员身份运行命令提示符，执行下方这行命令即可自动抓取本机名称并精准写入系统环境，绝无拼写错误风险： 
setx LSHOST %COMPUTERNAME% /M
命令成功执行后会显示 成功: 指定的值已保存。
极速生效

直达系统目录覆盖授权与服务重启

严禁使用老方法：切勿使用 Tools 目录下的 WlmAdmin 逐条导入证书，否则会导致程序白屏未响应长达三十分钟以上。

三秒极速生效做法：
1. 按键盘 Win + R 打开运行框，复制粘贴下方路径后按回车直接打开目标系统文件夹： 
C:\Program Files (x86)\Common Files\SafeNet Sentinel\Sentinel RMS License Manager\WinNT
2. 将解压包内 02-许可证 文件夹里的 lservrc 文件复制，直接粘贴覆盖到刚才打开的 WinNT 文件夹中。
3. 按 Win + R 输入 services.msc 按回车打开服务窗口，找到 Sentinel RMS License Manager，鼠标右键点击 重新启动 即可瞬间生效全部功能授权。
第四阶段

安装 Aspen 主程序与首次配置

步骤 9

启动安装向导与路径选择

来到 03-AspenspenONE_V11_ENG 文件夹，右键 Setup.exe 选择以管理员身份运行。

1. 点击 Install aspenONE products，勾选同意协议并点击 Next。
2. 在产品选择页面勾选需要的模拟组件，取消勾选无用的服务器工具以及基础工程组件。
3. 路径设置：有 D 盘的电脑点击 File Location 标签，把默认 C 盘的首字母全部更改为 D 盘；若是只有单个 C 盘的轻薄本，无需修改，直接保持默认 C 盘即可。
最关键避坑

许可证服务器输入框必须完全留空

全流程最重要的注意事项：进入许可证配置页面时，License server 与 License file 两个输入框必须保持完全空白，绝对不要点击 Add Server 添加计算机名，直接点击右下角 Next 跳过！

随后按提示输入统一密码例如 Aa123456，点击 Next 后点击 Install Now 开始正式安装主程序。安装过程大概需要十五至二十五分钟。

若中途弹出缺少 vc_red.msi 路径报错，直接点击浏览，导航至解压包内 03-AspenspenONE_V11_ENGspenonesuite\core credist_x86_VS2008SP1\ 选中该文件确定即可继续。
步骤 10

首次启动物性库初始化与跳过注册

在开始菜单找到 Aspen Plus V11 打开，首次启动时会弹出物性数据库初始化窗口，耗时一至三分钟，请耐心等待它自动完成进入主界面，切勿强行结束进程。

若弹出注册向导，选择无支持账户，随意填表后点击 Submit by internet 左侧网页链接，在弹出窗口点击 OK 确认并关闭帮助，即可永久进入软件主界面。
TROUBLESHOOTING & FAQ

常见高频避坑与极速排错字典

汇总历届学生装机实测中的典型问题，对号入座即可一分钟内快速脱困。

SQL 2012 安装提示 Database Engine Services Failed 红色叉号报错

问题成因：近几年的新款轻薄本或游戏本所配备的 NVMe 高速固态硬盘，其物理扇区大小汇报大于 4KB，导致旧版 SQL 2012 数据库引擎初始化时无法正常挂载系统数据库而崩溃报错。

排错步骤：
1. 点击安装窗口右下角 Close 退出，打开 Windows 设置中的已安装应用，找到 Microsoft SQL Server 2012 彻底卸载清除残留。
2. 以管理员身份运行命令提示符，执行以下扇区标准化修复命令： 
REG ADD "HKLM\SYSTEM\CurrentControlSet\Services\stornvme\Parameters\Device" /v "ForcedPhysicalSectorSizeInBytes" /t REG_MULTI_SZ /d "* 4095" /f
3. 立即重启电脑，重启后重新打开 sql2012 目录中的 setup.exe 重新安装即可全绿通过。
主程序安装到一半弹出弹窗寻找 vc_red.msi 路径

问题成因：Aspen 在静默释放 Visual C 2008 运行时临时解压包被系统提早清理，导致向导无法定位安装包源文件。

排错步骤：
在弹出的选择文件浏览对话框中，直接点击 Browse 浏览按钮，手动定位到你解压出的安装包内部目录：
03-AspenspenONE_V11_ENGspenonesuite\core credist_x86_VS2008SP1\
选中里面的 vc_red.msi 文件并点击确定，向导即可顺利继续完成安装。
轻薄本电脑只有一个 C 盘，没有 D 盘怎么安装

问题成因：不少新款笔记本出厂默认将所有固态硬盘空间全部划归为单个 C 盘。

排错指引：
完全不需要给硬盘重新分区或者借外接移动硬盘。只要确认 C 盘剩余可用空间大于三十吉字节，在第四阶段修改安装路径时直接保持默认的 C 盘路径直接安装即可，运行稳定性与多盘电脑没有任何区别。
打开软件弹出错误提示未能连接到有效的许可证服务器

问题成因：系统环境变量 LSHOST 未生效、许可证文件未放入系统目录，或者 Sentinel RMS 后台服务未处于运行状态。

排错步骤：
1. 以管理员身份运行命令提示符，执行 setx LSHOST %COMPUTERNAME% /M 重新写入本机计算机名。
2. 确认 lservrc 文件已被正确复制覆盖进系统 WinNT 目录。
3. 按 Win + R 输入 services.msc 找到 Sentinel RMS License Manager，右键选择重新启动。
软件界面如何自由切换简体中文或英文

操作方法：

点击电脑开始菜单，在所有程序中展开 Aspentech 文件夹，打开 Select Aspen Language Utility 工具，根据个人使用偏好勾选 Chinese 或 English，点击确定后重新启动软件即可完成界面语言切换。
