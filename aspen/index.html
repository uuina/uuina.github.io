CRITICAL GOTCHAS

核心避坑红线 (手动安装必读)

90% 的学生安装失败或耗时数小时，都是因为踩了以下三个传统教程未说明的隐藏陷阱：

避坑 1：向导第 67 步许可证界面必须【完全留空】！

在安装向导进入 Specify licensing & security 页面时：
❌ 绝对严禁点击 Add Server 添加计算机名！
❌ 绝对严禁在 License server 或 License file 输入框填写任何字符！

正确做法： 两个输入框均保持 100% 完全空白，直接点击右下角 Next > 跳过即可！后台脚本已经通过全局 LSHOST 环境变量完成双通道绑定，填入计算机会直接导致 "The version of the SLM License Server is not supported" 致命冲突。

避坑 2：中途弹出 "vc_red.msi 缺失网络路径" 报错

安装过程中，Windows Installer 可能弹窗提示：
"The feature you are trying to use is on a network resource that is unavailable... 'vc_red.msi' ... d:\[随机十六进制目录]\"
这是由于 Microsoft Visual C++ 2008 旧运行库找不到提取目录导致的。

一键解法： 打开 PowerShell 运行以下命令：
powershell -ExecutionPolicy Bypass -File .\preflight_and_patch.ps1 -Action patch-vcredist
脚本会自动将解压后的 vc_red.msi 和 vc_red.cab 注入到所有十六进制临时目录中。注入后直接点击弹窗上的 「OK」 即可继续，无需取消或重装！

避坑 3：首次启动弹出物性数据库恢复，切勿强行结束进程！

首次启动 Aspen HYSYS 或 Aspen Plus 时，界面会弹出：
"Aspen Properties Database Configuration: Restoring databases and creating config.aem..."

正确认知： 这是 Aspen 核心物性数据库的正常一次性初始化，耗时通常为 1 ~ 3 分钟。切勿误以为卡死而通过任务管理器杀掉进程，否则会导致物性数据库损坏、后续启动报缺少数据库错误。等待其自动加载完毕即可。
